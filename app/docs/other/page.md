# 其他

采用 `CP_Kernel` 的操作系统并非只有 CoolPotOS, CPOS除主仓库外也有其他的分支版本.

## 所有版本

* CoolPotOS: 采用 C 语言编写的 CoolPotOS, 是主要更新的版本
* CoolPotOS-V-x64: 采用 Vlang 语言编写的 CoolPotOS, 主仓库中 `x64` 架构的前身
* CoolPotOS-Riddle: 采用 Riddle 语言编写的 CoolPotOS, 是自制编程语言搭配自制操作系统的一次试验

## 其他操作系统

* MdrOS: 主仓库 `i386` 架构第二次重构版本的前身, `CP_Kernel` 内核的发行版之一.
