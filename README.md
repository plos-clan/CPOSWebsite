# CoolPotOS Documentation

The official CoolPotOS documentation site, built with Next.js, Nextra, and Bun.

```bash
bun install --frozen-lockfile
bun run dev
bun run check
bun run build
```

The production build is a static export. For Cloudflare Pages, use `bun run cf-build` as the build command and `out` as the output directory.
